DTS Go kit

Tools Diligent Technology Solutions uses on Windows machines it supports. Use it only when DTS asks you to.

Quickest: open PowerShell and paste:

irm https://go.diligenttech.net/get.ps1 | iex

It downloads the kit, checks it, and opens the menu (Windows asks for administrator rights).

Bench access - what it adds and how it goes away

  • A local administrator account dts-bench with a random password nobody sees; sign-in by key only.
  • OpenSSH Server, reachable only through DTS's private Tailscale network. This machine cannot reach anything on DTS's network, and its DNS and routes are not changed.
  • Tailscale, joined with a one-time key.
  • A record of every PowerShell command run during the session, kept in C:\ProgramData\DTS\BenchAccess.

At the end time (default 4 hours) a scheduled task removes all of it and writes the result to the Windows Application event log (source DTSBenchAccess). If the machine is off then, the cleanup runs when it next starts.
